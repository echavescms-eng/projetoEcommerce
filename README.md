PetShop Online

Um e-commerce simples para uma pet shop, desenvolvido com **HTML, CSS, JavaScript** e **Bootstrap 5**. O projeto apresenta produtos para pets e permite ao usuário navegar pelo catálogo, adicionar itens ao carrinho e acompanhar o valor da compra.

## Funcionalidades

- Catálogo de produtos para cães e gatos
- Exibição de nome, descrição, preço e imagem dos produtos
- Adição e remoção de itens do carrinho
- Atualização da quantidade e do total da compra
- Layout responsivo com Bootstrap 5
- Interface simples e intuitiva

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5

## Como executar

Este é um projeto front-end simplificado e não precisa de instalação de dependências ou servidor de banco de dados.

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Para uma experiência melhor durante o desenvolvimento, você pode abrir a pasta no Visual Studio Code e executar o `index.html` com a extensão **Live Server**.

## Estrutura sugerida

```text
petshop-ecommerce/

├── css/
│   └── style.css
```

## Bootstrap 5

O Bootstrap pode ser incluído no `index.html` usando os arquivos CDN oficiais. Confira a documentação para obter os links atualizados: [getbootstrap.com](https://getbootstrap.com/).

## Observações

Este projeto tem finalidade educacional e demonstra o fluxo básico de uma loja virtual no navegador. Os dados do carrinho são manipulados no front-end; não há integração com pagamento, banco de dados ou processamento real de pedidos.

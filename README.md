# 🪖 BizuExpress

Um e-commerce simples para um site online, desenvolvido com **HTML, CSS e JavaScript**. Aqui, os humanos encontram produtos para seus companheiros de quatro patas, exploram o catálogo e montam o carrinho com praticidade. 🎖️

## 🧭 O que dá para fazer

- ⚔️ Explorar produtos essenciais para você
- 🪺 Conferir nome, descrição, preço e imagem dos produtos
- 🛒 Adicionar e remover itens do carrinho
- 🧮 Acompanhar quantidades e o total da compra
- 📱 Navegar por um layout responsivo com Bootstrap 5
- ✨ Usar uma interface simples e intuitiva

## 🧰 Tecnologias

- 🧱 HTML5
- 🎨 CSS3
- 🪄 JavaScript (ES6+)

## 🚀 Como executar

Este é um projeto front-end simplificado: não precisa instalar dependências nem configurar um banco de dados.

1. 📥 Clone ou baixe este repositório.
   git clone https://github.com/echavescms-eng/projetoEcommerce.git

2. 📂 Abra a pasta do projeto.
   cd nome-pasta-projeto
   
3. 🌐 Abra `index.html` no navegador.

Para desenvolver com atualização automática da página, abra a pasta no Visual Studio Code e execute `index.html` usando a extensão **Live Server**. 🔄

## 🔎 Observações

Este projeto tem finalidade educacional e demonstra o fluxo básico de uma loja virtual no navegador. O carrinho funciona no front-end; não há integração com pagamento, banco de dados ou processamento real de pedidos. 📦
